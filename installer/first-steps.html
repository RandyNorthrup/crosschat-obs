CrossChat is installed

Four short steps and your stream chat is in one window.

  1. Add the script to OBS

    In OBS: Tools → Scripts → +, then pick
    %LOCALAPPDATA%\CrossChat\obs\crosschat.lua
    Setup put this path on your clipboard: paste it into the file box. From then on, CrossChat starts and stops with OBS. Using Streamlabs Desktop or another app? Skip this step and choose it in Settings → Channels & options → Streaming app.

  2. Set your channels

    Open CrossChat (Start menu → CrossChat → Open chat), then Settings, and enter your Twitch, YouTube, Kick, TikTok, Facebook, Instagram, Rumble and X details. Connect Twitch and Kick there to reply and moderate through their official APIs.

  3. Add the browser extension

    In Chrome, open CrossChat on the Chrome Web Store and press Add to Chrome. In Edge, press Allow extensions from other stores on that page first. It updates by itself from then on.
    Without the store: open chrome://extensions (or edge://extensions), switch on Developer mode, press Load unpacked and pick %LOCALAPPDATA%\CrossChat\extension.
    Twitch, YouTube, Kick and Rumble chat and the on-stream widgets work without it. Reading X, TikTok, Facebook and Instagram needs it, as do replies everywhere except Twitch and Kick, and X Live. It reads no logins.

  4. Put chat on your stream

    In your streaming app, add a Browser Source for each widget you want:
    Chat feedhttp://127.0.0.1:4466/overlay/chat450 × 800
    Featured messagehttp://127.0.0.1:4466/overlay/featured900 × 260
    Viewer counterhttp://127.0.0.1:4466/overlay/viewers600 × 120
    Alertshttp://127.0.0.1:4466/overlay/alerts800 × 300
    Restyle them in Start menu → CrossChat → Theme Studio. To try everything without going live: Start menu → CrossChat → Try the demo.

More help: the README in your CrossChat folder (%LOCALAPPDATA%\CrossChat\README.md), or github.com/RandyNorthrup/crosschat-obs.
